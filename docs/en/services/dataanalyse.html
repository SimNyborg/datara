Data collection and analysis

We begin with the question the data should help answer. We then collect, check and analyse the relevant data. The result is documented and presented so it can be used in the work that follows.

What the analysis includes

A checked set of data

We bring together data from the relevant sources and describe errors, gaps and the choices made along the way.

A method for the question

We choose the method according to the question, the amount of data and the uncertainty in it.

A result for further use

We present the result in charts, tables, maps or a short report, depending on how it will be used.

From question to result

  1. Define the question

    We clarify what the analysis needs to address and which data can be used.

  2. Collect and check the data

    We bring the data together, correct errors and describe gaps and uncertainty.

  3. Analyse the data

    We choose a method suited to the question and examine how reliable the result is.

  4. Document the result

    We bring the findings together and explain how they answer the question that started the analysis.
