Software development for workflows

We begin with the workflow and the people the software needs to support. We then define the features, build a prototype and test it with actual tasks. When the task is suitable, we use AI as a development tool because it can shorten development time and reduce costs.

What development includes

Features defined by the task

We build the features needed for the workflow and leave out the rest.

Testing with users

We test sketches and prototypes with actual tasks before building the full solution.

Code that can be maintained

We document the solution so errors can be corrected and features changed when needed.

From need to software

  1. Define the need

    We review the users, workflow and systems the solution needs to work with.

  2. Build a prototype

    We build a simple version of the main features and test it early.

  3. Develop and test

    We develop the solution step by step and test it with actual tasks. Code produced with AI support is reviewed and tested in the same way as other code.

  4. Put the solution into use

    We document and hand over the solution and agree how errors and changes will be handled.

Examples

  • Internal tools for specific workflows
  • Web solutions and simple tools customers can use themselves
  • Prototypes for testing new features
