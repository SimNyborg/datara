Udvikling af software til arbejdsgange

Vi starter med den arbejdsgang og de brugere, softwaren skal understøtte. Derefter afgrænser vi funktionerne, bygger en prototype og afprøver den med faktiske opgaver. Når opgaven egner sig til det, bruger vi AI som udviklingsværktøj, fordi det kan forkorte udviklingstiden og reducere omkostningerne.

Hvad udviklingen omfatter

Funktioner afgrænset til opgaven

Vi bygger de funktioner, der er nødvendige for arbejdsgangen, og undlader resten.

Afprøvning med brugerne

Vi tester skitser og prototyper med faktiske opgaver, før hele løsningen bliver bygget.

Kode, der kan vedligeholdes

Vi dokumenterer løsningen, så fejl kan rettes og funktioner ændres, når behovet opstår.

Fra behov til software

  1. Afgræns behovet

    Vi gennemgår brugerne, arbejdsgangen og de systemer, løsningen skal fungere sammen med.

  2. Byg en prototype

    Vi bygger en enkel version af de vigtigste funktioner og afprøver den tidligt.

  3. Udvikl og test

    Vi udvikler løsningen trin for trin og tester den med faktiske opgaver. Kode lavet med hjælp fra AI bliver gennemgået og testet som anden kode.

  4. Sæt løsningen i drift

    Vi dokumenterer løsningen, overdrager den og aftaler, hvordan fejl og ændringer håndteres.

Eksempler

  • Interne værktøjer til konkrete arbejdsgange
  • Webløsninger og enkle selvbetjeningsforløb
  • Prototyper til afprøvning af nye funktioner
